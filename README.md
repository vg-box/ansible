# boxes-ansible

『우아하게 앤서블』과 Ansible 강의 실습에서 사용하는 Vagrant box의 배포용 사본입니다.

| box | 버전 |
|---|---|
| `sysnet4admin/nxosv_v7` | 7.0.3.I7.8 |
| `sysnet4admin/nxosv_v9` | 9.2.3 |
| `sysnet4admin/VyOS` | 1.1.8.1 |
| `CumulusCommunity/cumulus-vx` | 3.6.0 |

- box 파일은 [Releases](https://github.com/vg-box/boxes-ansible/releases)에 있습니다. 같은 Release의
  `SHA256SUMS`로 내려받은 파일을 확인할 수 있습니다.
- 카탈로그는 [vg-box/boxes](https://github.com/vg-box/boxes)의 GitHub Pages에 있습니다.
- 각 이미지의 라이선스는 원래 배포처의 조건을 따릅니다.
